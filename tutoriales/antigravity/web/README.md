# Primeros pasos con IA agéntica

Sitio HTML estático, autocontenido y en español para publicar en Netlify Drop. Incluye módulo práctico de colaboración con Git, GitHub y GitHub Desktop (repositorios, ramas, commits, pull requests, conflictos y agentes).

## Publicación en Netlify Drop

1. Utiliza la carpeta `tutoriales/antigravity/web/` de esta entrega.
2. Ve a https://app.netlify.com/drop
3. Arrastra la carpeta **web** (la que contiene `index.html`) a la zona de publicación.
4. Espera a que Netlify indique la URL pública y ábrela.

No requiere instalación de Node, compilación, dependencias, API, cuenta de pago ni configuración de variables de entorno. También puedes abrir `index.html` directamente en el navegador para una vista previa local.

## Estructura

- `index.html`: contenidos, secciones y enlaces.
- `assets/styles.css`: diseño adaptable y tema claro/oscuro.
- `assets/app.js`: botones para copiar prompts y selector de tema.
- `assets/favicon.svg`: favicon original simple.
- `netlify.toml`: cabeceras de seguridad y configuración de publicación.

## Personalización

Edita el texto en `index.html`. Los colores principales están definidos al inicio de `assets/styles.css`.

## Módulo Git/GitHub

Contiene un itinerario visual para dos personas que colaboran sobre un repositorio compartido, una alternativa con comandos Git y un prompt de colaboración supervisada para Antigravity. La propuesta exige revisión humana antes de merges o publicaciones y advierte sobre credenciales, `.gitignore` y conflictos.

Referencias: https://docs.github.com/es/get-started/using-github/hello-world y https://docs.github.com/es/get-started/learning-to-code/getting-started-with-git


## Actualización: tres formas de colaboración

La sección «Tres formas de colaborar» distingue colaboración humana, coordinación entre agentes y reproducibilidad. Incluye un ejercicio en parejas, un prompt copiable y una lista de comprobación. La navegación superior de escritorio se mantiene en cinco enlaces; para pantallas menores de 901 px se usa un menú desplegable accesible que se cierra al elegir un destino o pulsar Escape.
